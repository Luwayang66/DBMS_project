# DBMS Project

This project contains database schemas and basic data manipulation scripts for five different management systems.

## Systems Included

1. **Result Processing**: Management of students, courses, enrollments, and academic results.
2. **Billing System**: Customer invoicing and product billing.
3. **Library System**: Book inventory and member borrowing tracking.
4. **Hospital Management**: Patient records, doctor appointments, and medical treatments.
5. **Supermarket POS**: Point-of-Sale system for retail product sales and cashier tracking.

## Structure

Each system is organized into its own directory containing a `schema.sql` file with the table definitions and initial test data.
